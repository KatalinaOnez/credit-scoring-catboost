# Credit Scoring: Прогнозирование дефолта заемщика

Решение классической задачи по разработке модели машинного обучения для оценки рисков выдачи кредита банка. Основная цель - предсказать вероятность дефолта заемщика на основе кредитной истории клиентов и социальных данных.

## Описание проекта
В ходе работы был реализован полный цикл разработки ML-исследования (End-to-End):
*   **Глубокий разведочный анализ данных (EDA):** выявление ключевых факторов риска и визуализация зависимостей.
*   **Предобработка данных:** очистка от аномалий, обработка пропусков и создание новых признаков (Feature Engineering).
*   **Моделирование:** сравнительный анализ моделей различной архитектуры (линейные модели vs ансамбли).

## Стек
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy, Matplotlib, Seaborn
* **ML-алгоритмы:** 
  * Logistic Regression (Baseline)
  * Random Forest
  * **CatBoost Classifier** (SOTA-решение)

## Результаты
Для обучения и тестирования использовались разделенные выборки (Train/Test). Наилучшие показатели продемонстрировала модель **CatBoost**:

*   **Accuracy:** ~94%
*   **Recall (Полнота):** ~74% — модель успешно идентифицирует 3 из 4 потенциальных дефолтов.
*   **Precision:** ~97.6% — крайне низкий уровень ложных отказов для благонадежных клиентов.

## Бизнес-вывод
Приоритетной метрикой выбран **Recall**, так как для банка критически важно минимизировать ошибки II рода (выдачу кредита неблагонадежному заемщику). Модель позволяет существенно снизить кредитные убытки, сохраняя при этом высокий уровень одобрения для надежных клиентов благодаря высокой точности (Precision).
